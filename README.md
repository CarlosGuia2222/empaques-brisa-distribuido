# Sistema Distribuido de Cotizaciones - Empaques Brisa

Proyecto PIA para la materia de Sistemas Distribuidos y Paralelos.

## Descripción general

Este proyecto consiste en el desarrollo de un sistema web distribuido para la empresa Empaques Brisa, con el objetivo de digitalizar el proceso de cotizaciones, reducir errores de cálculo y mejorar la organización de la información.

## Tecnologías principales

- React + Vite
- Firebase Authentication
- Cloud Firestore
- Node.js + Express
- GitHub
